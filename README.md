# Identity, Access Control, and Data Protection

## Project Overview

This project demonstrates Identity and Access Management (IAM) practices using Microsoft Entra ID.

## Permission Remediation

Reviewed role assignments and applied the Principle of Least Privilege.

**Example:** Removed Global Administrator from an IT Support Specialist and assigned Helpdesk Administrator.

## Data Encryption

Protected project files using 7-Zip with AES-256 encryption and password protection.

## Tools

- Microsoft Entra ID
- GitHub
- 7-Zip (AES-256)

## Key Skills

- IAM and Role-Based Access Control (RBAC)
- Least Privilege
- Permission Remediation
- File Encryption
